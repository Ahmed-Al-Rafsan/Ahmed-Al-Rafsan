## Start here

### 01 / Australian schools priority targeting

**Industry capstone · Team Lead & Data Analyst**

Which schools should a small Australian business approach first? Our engagement covered **9,855 schools**, combining a transparent priority score, K-Means segmentation and a CRM-ready outreach list. I led the team and the analytics workstream, with an executive Power BI dashboard among the deliverables.

**Technical decision:** the Random Forest inputs exclude the variable used to define the high-priority label. The project reports a held-out **ROC-AUC of 0.972** on the original dataset. This measures recovery of that priority label; it does **not** establish sales conversion or validate the business value of the scoring rule.

**Public evidence:** Python analysis, methodology and a synthetic demonstration dataset. The original client data and client dashboard remain private; the reported engagement metric is not a benchmark for the synthetic demo.

`Python` `pandas` `scikit-learn` `K-Means` `Random Forest` `Power BI`

## How I approach the work

- **Define the decision.** Start with the question, audience and meaning of each metric.
- **Examine the data.** Check completeness, uniqueness, validity, consistency and outliers; document treatment choices.
- **Explain the reasoning.** Make methods, assumptions and limitations visible alongside the results.
- **Make the handover useful.** Connect code and analysis to clear documentation, dashboards and next actions.
